# Royal TSX 简体中文语言包

为 Royal TSX **6.4.5（macOS）**制作的非官方简体中文语言包。

主程序语言文件包含 1,938 个条目，覆盖菜单、工具栏、连接属性、凭据、网关、任务、设置及提示。品牌名称、协议名、命令示例和格式占位符保留原文。

## 下载

[下载 6.4.5 简体中文语言包](downloads/Royal-TSX-6.4.5-zh-Hans.zip)，或使用仓库中的 `zh-Hans.lproj` 文件夹。

## 安装

1. 保存正在编辑的文档，退出 Royal TSX。退出会断开活动连接。
2. 在访达中找到 `/Applications/Royal TSX.app`，右键选择“显示包内容”。
3. 打开 `Contents/Resources`，将语言包的 `zh-Hans.lproj` 文件夹复制到这里。
4. 确保 macOS 首选语言为简体中文，再启动 Royal TSX。

若应用安装在其他位置，请使用对应应用的 `Contents/Resources` 目录。

安装前若已存在 `zh-Hans.lproj`，请先将它备份到应用包外。不要覆盖或删除原有的 `en.lproj` 和 `de.lproj`。

## 恢复

退出 Royal TSX，移除本次添加的 `Contents/Resources/zh-Hans.lproj` 文件夹；如安装前已有同名目录，则恢复备份。重新启动应用即可。

## 兼容性与验证

- 针对 Royal TSX 6.4.5 的主程序英文语言资源制作。
- 全部 1,938 个键均保留，格式占位符已检查，`plutil -lint` 检查通过。
- 在 macOS 简体中文语言环境下实际重启，确认主菜单、工具栏、仪表板和常规设置显示中文。
- 未逐一测试所有连接类型和全部提示框。第三方插件、网页内容、用户自定义名称及少量写死的英文不在覆盖范围。
- 应用更新可能移除语言包；其他版本应先核对语言资源，再安装。

## 应用签名

向应用包添加语言资源会导致原应用的代码签名资源校验不通过。测试机器上应用仍可正常启动，但不能保证其他系统环境下同样可用。

此语言包不包含重新签名操作，也不要求关闭系统安全保护。若系统阻止启动，请移除新增语言文件夹以恢复原包，或从官方来源重新安装应用。
